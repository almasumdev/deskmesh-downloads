# DeskMesh downloads

Installers for [DeskMesh](https://github.com/almasumdev/deskmesh-downloads/releases/latest): one keyboard and mouse across all your computers on the same network.

Get the file for your computer from the [latest release](https://github.com/almasumdev/deskmesh-downloads/releases/latest). The app updates itself after that.

| Computer | File |
|---|---|
| Mac | `DeskMesh-<version>-macos.zip` |
| Windows | `DeskMesh-<version>-windows-setup.exe` |
| Ubuntu, Debian | `deskmesh-<version>-linux-amd64.deb` |
| Fedora and similar | `deskmesh-<version>-linux-x86_64.rpm` |

This repo holds only the installers. The files aren't code-signed by Apple or Microsoft yet, so your computer may warn on first install.
